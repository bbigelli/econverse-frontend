## 📋 Sobre o Projeto

A **Econverse** é uma plataforma de e-commerce moderna desenvolvida em React com TypeScript, oferecendo uma experiência de compra completa e intuitiva. O projeto apresenta vitrine de produtos, categorias, banner promocional, newsletter e um design totalmente responsivo.

### ✨ Funcionalidades

- 🏠 **Homepage completa** com vitrine de produtos
- 📱 **Design responsivo** para todos os dispositivos
- 🏷️ **Categorias de produtos** (Tecnologia, Moda, Esportes, etc.)
- 🔍 **Busca de produtos** com ícone interativo
- 🛒 **Carrinho de compras** (em desenvolvimento)
- 📧 **Newsletter** com validação de termos
- 🎨 **Interface moderna** com animações suaves
- ♿ **Acessibilidade** com ARIA labels

## 🚀 Tecnologias Utilizadas

### Frontend
- **React 18** - Biblioteca UI

## 🛠️ Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

- **[Git](https://git-scm.com)** (para clonar o repositório)
- **[Node.js](https://nodejs.org)** (versão 16 ou superior)
- **[npm](https://www.npmjs.com/)** ou **[yarn](https://yarnpkg.com/)** (gerenciador de pacotes)

Para verificar as versões instaladas:

node --version   # Deve ser v16.x ou superior
npm --version    # Deve ser v8.x ou superior
git --version    # Deve ser v2.x ou superior

### 📦 Instalação
1. Clone o repositório
# Clone via HTTPS
git clone https://github.com/bbigelli/econverse-frontend.git

# Acesse a pasta do projeto
cd econverse
2. Instale as dependências
# Usando npm
npm install

# Ou usando yarn
yarn install

3. Execute o projeto
# Modo desenvolvimento
npm run dev

# Ou com yarn
yarn dev

O projeto estará disponível em: http://localhost:5173

### 📱 Responsividade
O projeto é totalmente responsivo e se adapta aos seguintes breakpoints:

Desktop: > 1200px

Tablet: 768px - 1199px

Mobile: < 768px

Testado nos navegadores:

✅ Google Chrome (última versão)

### 🎨 Personalização
Cores Principais
As cores do tema podem ser alteradas no arquivo src/assets/styles/global.scss:
// Cores principais
$yellow: #FFD700;        // Amarelo principal
$blue: #1100ff;          // Azul para botões
$header-bg: #1a1225;     // Roxo escuro do header
$white: #FFFFFF;          // Branco
$text-dark: #333333;      // Texto escuro
$text-light: #666666;     // Texto claro
